## 如何获取 Avatar ID

1. 登录 HeyGen 平台：https://app.heygen.com/
2. 进入 "Avatars" 页面
3. 选择或创建你的 Avatar
4. 点击 Avatar 详情，复制 Avatar ID（格式如：`xxx_xxx_xxx`）
5. 将 ID 填入上方对应位置
