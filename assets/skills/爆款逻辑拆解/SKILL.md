# Video TSS Faddish Disassemble Skill

## Overview

This skill analyzes AI-generated video summaries (from video-to-subtitle-summary) to extract viral content patterns and generate actionable content creation guides.

**Core Workflow:**
1. Read video analysis reports (final_analysis_report.md)
2. Extract viral logic patterns (hooks, structure, psychology)
3. Generate faddish logic analysis report
4. Create industry-specific content scripts

**Input Source:**
- Output from `video-to-subtitle-summary` skill
- Path: Typically `C:\tmp\video_analysis\{video_id}\final_analysis_report.md`

**Output:**
- Faddish logic analysis report (saved to Desktop)
- Industry-specific short video scripts (saved to Desktop)

## When to Use

- User provides video analysis reports and asks for viral logic disassembly
- User wants to understand why certain videos become popular
- User needs content creation guidance for specific industries
- User requests "爆款逻辑拆解" or similar

## Core Process

### Step 0: Identify Input Source

Determine the source of video analysis reports from video-to-subtitle-summary skill.

**Important:** The AI analysis report from video-to-subtitle-summary skill may have different names:
- `final_analysis_report.md` (most common)
- `analysis_result.md` (alternative naming)
- User may also save with custom names

**Option A: Direct Path Provided**
- User provides specific path to analysis report
- Use provided path directly
- If the file doesn't exist, ask user to confirm the correct path

**Option B: Standard Location (Auto-discovery)**
- Default path: `C:\tmp\video_analysis\`
- List all subdirectories (each subdirectory = one analyzed video)
- In each subdirectory, look for AI analysis report with these patterns (in order):
  1. `final_analysis_report.md`
  2. `analysis_result.md`
  3. Any `.md` file containing "analysis" or "report" in filename
  4. If multiple matches, prefer the most comprehensive one (largest file size)
- If no report found in a subdirectory, note it and continue with others

**Option C: Multiple Videos for Comparison**
- If multiple video reports exist, read all for comparative analysis
- Generate both individual and comparative reports

**Discovery Command:**
```powershell
# List all video analysis directories
$dirs = Get-ChildItem -Path "C:\tmp\video_analysis" -Directory

# Find analysis report in each directory
foreach ($dir in $dirs) {
    $report = Get-ChildItem -Path $dir.FullName -Filter "*.md" | 
              Where-Object { $_.Name -match "analysis|report" } |
              Sort-Object Length -Descending | 
              Select-Object -First 1
    if ($report) {
        # Found report: $report.FullName
    }
}
```

### Step 1: Read Video Analysis Reports

Read the discovered analysis report file(s) to extract viral content patterns.

**Files to Look For:**
| Priority | Filename | Description |
|----------|----------|-------------|
| 1 | `final_analysis_report.md` | Most common output from video-to-subtitle-summary |
| 2 | `analysis_result.md` | Alternative naming |
| 3 | `*analysis*.md` / `*report*.md` | User-customized names |

**Key Sections to Extract:**
```markdown
1. Video metadata (platform, author, duration, views/likes)
2. AI-generated title
3. Content summary
4. Core points/key arguments
5. Full subtitle text (for language pattern analysis)
6. Generated files list
```

**Reading Commands:**
```powershell
# If specific path provided
Get-Content -Path "{user_provided_path}" -Raw

# If auto-discovering from standard location
$reportFile = Get-ChildItem -Path "C:\tmp\video_analysis\{video_id}" -Filter "*.md" |
              Where-Object { $_.Name -match "final_analysis|analysis_result|report" } |
              Sort-Object Length -Descending |
              Select-Object -First 1

if ($reportFile) {
    $content = Get-Content -Path $reportFile.FullName -Raw
} else {
    # Try any .md file as fallback
    $anyMd = Get-ChildItem -Path "C:\tmp\video_analysis\{video_id}" -Filter "*.md" |
             Select-Object -First 1
    if ($anyMd) {
        $content = Get-Content -Path $anyMd.FullName -Raw
    }
}
```

**Error Handling:**
- If no analysis report found → Ask user: "未找到视频分析报告，请提供正确的文件路径"
- If file is empty or unreadable → Note in output and continue with available data
- If multiple reports found → Read all for comparative analysis

### Step 2: Analyze Viral Logic Patterns

Analyze the following viral content dimensions:

#### 2.1 Title/Hooks Analysis
| Element | What to Analyze | Example Findings |
|---------|-----------------|------------------|
| **Urgency** | Time-sensitive words | "今天" "即将" "马上" |
| **Curiosity Gap** | Information asymmetry | "90%的人不知道" |
| **Emotion** | Fear/FOMO/Excitement | "危机将至" "机会来了" |
| **Specificity** | Numbers/Data | "37亿美元" "3天到账" |

#### 2.2 Content Structure Analysis
```
Standard Viral Structure:
├── Hook (0-3s): Grab attention immediately
├── Problem/Context (5-15s): Set up the issue
├── Proof/Analysis (15-35s): Data, examples, logic
├── Solution/Insight (35-45s): Key takeaway
└── CTA (45-50s): Call to action
```

#### 2.3 Psychological Triggers
| Trigger | How It's Used | Effect |
|---------|---------------|--------|
| **Fear Appeal** | "危机" "爆雷" "撑不下去" | Drives sharing (warn others) |
| **FOMO** | "机会" "好消息" "别错过" | Drives engagement |
| **Authority** | Data, expert names, institutions | Builds credibility |
| **Social Proof** | "很多人" "90%" "大家" | Creates bandwagon |
| **Urgency** | "今年" "马上" "现在" | Forces immediate action |

#### 2.4 Language Patterns
- **Sentence length**: Short, punchy sentences work better
- **Vocabulary**: Simple words over jargon ("拿好" vs "持有")
- **Transitions**: "那接下来" "所以" "你看" to guide flow
- **Repetition**: Key points repeated for emphasis

### Step 4: Generate Industry-Specific Scripts

Based on the viral logic analysis, create short video scripts for target industries.

**Output Files:**
1. `{industry}短视频文案_{timestamp}.md` - Standard text scripts
2. `{industry}口播拍摄脚本_{timestamp}.md` - **NEW: Standard broadcast script for digital human/real person shooting**

**Script Types to Include:**
1. **Crisis Warning Type** - Create urgency and attention
2. **Opportunity Sharing Type** - Positive, actionable content
3. **Educational/How-To Type** - Build authority and trust
4. **Story/Case Study Type** - Emotional connection
5. **Hot Topic/Trend Type** - Timely, news-driven

**Standard Text Script Template (File 1):**
```markdown
### 文案X：{Type Name}

**标题：** [Viral title using analyzed patterns]

**正文（约XX秒）：**

【开场 - X秒】
[Hook using urgency/curiosity/emotion]

【论证 - X秒】
[Body with data/proof/examples]

【收尾 - X秒】
[CTA with clear next step]

**拍摄建议：**
- Scene selection
- Clothing/style
- Tone/pace
- Subtitle tips

**发布策略：**
- Best timing
- Hashtags
- Comment engagement
```

### Broadcast Script Column Standards

**画面提示 (Visual Cues):**
Must include at least 2 of these elements:
- 【景别】特写/中景/全景
- 【场景】具体地点描述
- 【动作】肢体动作指导
- 【道具】手持或背景物品
- 【服装】穿着要求

**字幕文案 (Subtitle Text):**
- Max 15 Chinese characters per screen
- Split into 2 lines if needed
- Key numbers/data highlighted
- No punctuation at line breaks
- Punchy, rhythmic language

**语气情绪 (Tone & Emotion):**
Must specify:
- 【情绪】紧张/兴奋/严肃/亲切/权威...
- 【语速】快(紧迫感)/中(正常)/慢(强调)
- 【音量】高(强调)/中/低(神秘)
- 【重音】关键词标注

**时间 (Timing):**
- Each shot: 3-8 seconds
- Hook shot: 0-3 seconds
- CTA shot: last 5 seconds
- Total: 30-60 seconds

## Best Practices

1. **Always compare multiple videos** when available - patterns emerge from comparison
2. **Focus on actionable insights** - not just what worked, but why and how to replicate
3. **Adapt to target industry** - financial viral logic ≠ food industry viral logic
4. **Include compliance warnings** - financial content has regulatory requirements
5. **Provide specific examples** - generic advice is less valuable than concrete scripts
