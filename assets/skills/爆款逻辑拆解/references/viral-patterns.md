# 常见爆款内容模式

## 一、标题公式库

### 1. 危机预警型
```
【人群】+ 注意！+ 【负面事件】+ 将至/来了
例："餐饮老板注意！今年这3类店可能撑不下去"

【数字】%+ 的人 + 还不知道 + 【重要信息】
例："90%的餐饮老板还不知道这个新政策"

【时间】+ 前 + 【人群】+ 必须 + 【行动】
例："年底前，有贷款的老板必须做这件事"
```

### 2. 机会分享型
```
【人群】+ 好消息！+ 【利益点】
例："餐饮老板好消息！今年贷款容易多了"

【时间】+ 【领域】+ 有个 + 【机会】+ 很多人不知道
例："今年餐饮业有个机会，很多人还不知道"

【动作】+ 能 + 【省钱/赚钱】+ 【数字】
例："换个收款码，一年能省5000块"
```

### 3. 干货教学型
```
【人群】+ 【动作】+ 第一步就错了
例："餐饮店贷款，90%的老板第一步就错了"

【领域】+ 千万别 + 【错误做法】
例："贷款千万别先找银行！"

【数字】+ 个 + 【领域】+ 技巧 + 帮你 + 【好处】
例："3个贷款技巧，帮你多批10万块"
```

### 4. 故事案例型
```
这个 + 【人群】+ 【动作】+ 多 + 【结果】
例："这个火锅店老板，用了一招多活了3年"

【数字】+ 万 + 【事件】+ 他是 + 【结果】
例："欠了20万，他是怎么翻身的"

从 + 【低谷】+ 到 + 【成功】+ 只做了 + 【动作】
例："从濒临倒闭到开第二家店，他只做了这件事"
```

## 二、开场钩子库（前3秒）

### 高冲击力开场
| 类型 | 模板 | 示例 |
|------|------|------|
| **危机型** | 【人群】，【负面事件】来了！ | "开店的老板，危机来了！" |
| **机会型** | 【人群】，好消息！ | "餐饮老板，好消息！" |
| **反常识型** | 【普遍认知】？错了！ | "先找银行？错了！" |
| **数据型** | 【数字】%的人 + 【状态】 | "90%的店都犯这个错" |
| **悬念型** | 你知道 + 【问题】+ 吗？ | "你知道为什么你的贷款总被拒吗？" |

### 情绪调动开场
- **恐惧**："大危机来了！"
- **好奇**："有个秘密，90%的人不知道"
- **兴奋**："机会来了！"
- **愤怒**："又被坑了！"
- **共鸣**："开店太难了"

## 三、内容结构模板

### 模板A：危机-分析-解决
```
[0-3s] 危机钩子
[3-10s] 问题描述（具体化）
[10-25s] 分析原因（3个要点）
[25-40s] 解决方案
[40-45s] 行动号召
```

### 模板B：机会-条件-行动
```
[0-3s] 机会钩子
[3-12s] 机会描述（是什么）
[12-25s] 适用条件（谁能做）
[25-38s] 具体好处（数字支撑）
[38-45s] 行动号召
```

### 模板C：误区-正解-案例
```
[0-3s] 反常识钩子
[3-12s] 常见误区（制造共鸣）
[12-30s] 正确做法（3步法）
[30-40s] 真实案例（增强可信度）
[40-45s] 收藏/关注号召
```

## 四、数据使用技巧

### 让数据更有冲击力
| 原始表达 | 优化表达 | 效果 |
|---------|---------|------|
| 很多钱 | 37亿美元 | 具体可信 |
| 很多人 | 150位高管 | 有画面感 |
| 很大 | 3万亿美元 | 震撼 |
| 省了钱 | 省了7500块，够发一个月工资 | 可感知 |
| 很快 | 3天到账 | 明确 |

### 数据对比法
```
以前：X元 → 现在：Y元 → 省了：Z元（相当于...）
例："以前利息2万5，现在1万7，省了7500，够发一个月工资"
```

## 五、语言风格指南

### 口语化替换表
| 书面语 | 口语化 | 场景 |
|--------|--------|------|
| 申请 | 办/弄 | "办个贷款" |
| 持有 | 拿好 | "拿住别动" |
| 震荡整理 | 调整两天 | "可能要调整两天" |
| 压力位 | 涨到这儿有点难 | "涨到这儿有点难" |
| 资产配置 | 钱怎么放 | "钱怎么放" |
| 收益率 | 能赚多少 | "能赚多少" |

### 连接词使用
- **递进**："那接下来" "更重要的是" "最关键的是"
- **转折**："但是" "不过" "要注意的是"
- **总结**："所以" "说白了" "一句话"
- **举例**："比如说" "像我有个客户" "你看"

## 六、结尾CTA模板

### 关注/私信型
- "你是哪一类？评论区说说"
- "想知道你能贷多少？私信我"
- "评论区扣1，我发你详细资料"

### 收藏/转发型
- "这条很重要，建议收藏"
- "转发给需要的朋友"
- "保存起来，用得上"

### 下期预告型
- "下期告诉你，现金流紧张怎么破局"
- "关注我，下次讲具体操作"
- "明天更新，别错过"
