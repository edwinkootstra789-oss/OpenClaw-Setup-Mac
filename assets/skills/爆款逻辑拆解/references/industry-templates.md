# 行业特定文案模板

## 一、餐饮业模板

### 痛点分析
- 房租压力大
- 客流不稳定
- 现金流紧张
- 淡季难熬
- 竞争激烈

### 文案框架
```
标题：【数字】类餐饮店今年最危险 / 餐饮老板好消息！

开场：开店的老板，【危机/机会】来了！

主体：
- 第一类：纯做堂食的（外卖占比60%）
- 第二类：不会算账的（流水20万，利润几千）
- 第三类：现金流断的（交租就头疼）

解决方案：
- 贷款渡过难关
- 上团购引流
- 优化成本结构

结尾：你是哪一类？评论区说说
```

## 二、零售业模板

### 痛点分析
- 库存积压
- 资金周转慢
- 电商冲击
- 租金上涨
- 客户流失

### 文案框架
```
标题：实体店还能开吗？这3类店正在悄悄赚钱

开场：都说实体店难做，但这3类店正在悄悄赚钱！

主体：
- 第一类：社区便利店（高频刚需）
- 第二类：体验式零售（无法被电商取代）
- 第三类：会员制店铺（锁定长期客户）

关键成功因素：
- 位置选择
- 资金周转
- 客户运营

结尾：你的店属于哪一类？
```

## 三、制造业模板

### 痛点分析
- 原材料涨价
- 订单不稳定
- 设备更新慢
- 账期长
- 人工成本高

### 文案框架
```
标题：工厂老板注意！今年这3类厂可能被淘汰

开场：开厂的老板，行业大洗牌来了！

主体：
- 第一类：没有核心技术的（容易被替代）
- 第二类：现金流管理差的（账期拖垮）
- 第三类：不更新设备的（效率落后）

转型建议：
- 设备升级贷款
- 订单融资
- 供应链金融

结尾：你的工厂有这些问题吗？
```

## 四、服务业模板（美容/健身/教育等）

### 痛点分析
- 获客成本高
- 客户留存难
- 预付卡风险
- 人员流动大
- 场地租金贵

### 文案框架
```
标题：【行业】店今年有个机会，很多人还不知道

开场：开【行业】店的老板，今年有个好消息！

主体：
- 机会：消费升级/政策支持/市场空白
- 挑战：竞争加剧/成本上升/客户挑剔
- 破局：差异化定位/会员体系/资金储备

实操建议：
- 如何用贷款扩张
- 如何设计预付方案
- 如何提高复购率

结尾：想知道具体怎么做？私信我
```

## 五、电商/微商模板

### 痛点分析
- 流量成本暴涨
- 平台规则多变
- 库存风险
- 现金流紧张
- 竞争激烈

### 文案框架
```
标题：电商卖家注意！平台又出新规，这3类店铺最危险

开场：做电商的卖家，平台大整顿来了！

主体：
- 第一类：刷单造假的（直接封店）
- 第二类：资金链脆弱的（库存积压就完蛋）
- 第三类：单一平台的（风险集中）

应对策略：
- 多平台布局
- 合理备货
- 资金周转方案

结尾：你是做哪个平台的？评论区聊聊
```

## 六、通用模板要素

### 无论什么行业都适用

#### 1. 时间紧迫感
- "今年"
- "马上"
- "年底前"
- "最后机会"

#### 2. 人群精准定位
- "【行业】老板"
- "做【业务】的"
- "开【店型】的"

#### 3. 数字具体化
- "3类"
- "90%"
- "省了X万"
- "3天到账"

#### 4. 情绪词汇
- 危机类："危险" "淘汰" "撑不下去" "出事"
- 机会类："好消息" "机会" "红利" "风口"

#### 5. 行动指令
- "评论区扣1"
- "私信我"
- "收藏起来"
- "转发给需要的朋友"

## 七、行业适配检查清单

创建新行业文案时检查：

- [ ] 该行业的核心痛点是什么？
- [ ] 目标客户日常用语是什么？
- [ ] 行业特有的数据/指标有哪些？
- [ ] 该行业最近有什么热点/政策？
- [ ] 客户最关心的问题是什么？
- [ ] 什么场景下他们会看视频？
- [ ] 什么内容会让他们愿意分享？

```markdown
### 拍摄总要求

**画面要求：**
- 分辨率：1080P或4K
- 光线：店内自然光或LED柔光灯
- 背景：真实餐厅环境，避免杂乱
- 稳定性：三脚架固定，避免晃动

**音频要求：**
- 清晰无杂音（避开饭点嘈杂时段）
- 背景音乐：紧张感电子乐，音量低于人声20%
- 关键数据"60%""20万"配合提示音

**字幕要求：**
- 字体：粗体黑体，黄色加黑边
- 位置：画面下方1/4处
- 关键数字"60%""20万"放大1.5倍
- 每行最多8个字

### 数字人适配说明

**如使用数字人：**
- 场景可用虚拟餐厅背景
- 动作简化为：直视镜头、手势比划、点头摇头
- 表情变化：严肃→担忧→震惊→亲和
- 避免复杂走动和道具交互

**如真人拍摄：**
- 提前准备围裙/厨师服
- 准备计算器、账本等道具
- 熟记台词，做到自然表达
- 注意眼神看镜头，与观众建立连接
```

### 口播脚本设计原则

1. **3秒定生死**：第一镜必须是强钩子，画面+字幕+语气三重冲击
2. **数据可视化**：关键数字用特写镜头，字幕放大显示
3. **情绪曲线**：紧张→担忧→震惊→希望→亲和，有起伏才有完播率
4. **动作配合**：每个镜头都有明确动作指导，避免呆板站立
5. **字幕节奏**：每3-5秒切换一次字幕，保持视觉新鲜感
6. **CTA明确**：最后一镜必须引导互动（评论/私信/关注）
