# 每日复盘 (Daily Review) - GRAI复盘法

本技能基于GRAI复盘法，帮助用户系统化梳理经验、提炼方法论。

## 什么是GRAI复盘法

GRAI复盘法通过四个环节进行深度分析：

1. **Goal（目标回顾）**：明确最初设定的目标，判断是否偏离或达成
2. **Result（结果评估）**：对比实际结果与目标，分析亮点与不足
3. **Analysis（原因分析）**：从流程、规则、执行等角度剖析成功或失败的主客观因素
4. **Insight（规律总结）**：提炼可复用的方法论，制定改进计划

## 使用场景

- 项目复盘
- 季度总结
- 个人成长回顾
- 大型活动复盘
- 每日/每周工作总结

## 工作流程

### 1. 引导用户回顾目标 (Goal)

询问用户：
- 最初设定的目标是什么？
- 目标是否清晰、可衡量？
- 是否有多个目标？优先级如何？

### 2. 评估实际结果 (Result)

引导用户对比：
- 实际完成了什么？
- 与目标的差距是多少？
- 有哪些超出预期的亮点？
- 有哪些未达预期的不足？

### 3. 分析原因 (Analysis)

从多个维度剖析：
- **主观因素**：个人执行力、技能水平、态度等
- **客观因素**：资源、环境、外部支持等
- **流程因素**：方法是否正确、步骤是否合理
- **规则因素**：制度、约束条件是否影响结果

### 4. 总结规律与改进 (Insight)

帮助用户提炼：
- 哪些做法值得继续？
- 哪些错误需要避免？
- 可复用的方法论是什么？
- 下一步的改进计划？

## 输出格式

复盘完成后，生成结构化的复盘文档。使用模板：`assets/review-template.md`

## 交互方式

1. 主动引导用户完成四个步骤
2. 每个步骤提出关键问题
3. 根据用户回答进行追问和澄清
4. 最后生成完整的复盘报告

## 复盘模板

复盘文档应包含以下部分：
- 复盘主题/标题
- 复盘日期
- Goal（目标回顾）
- Result（结果评估）
- Analysis（原因分析）
- Insight（规律总结）
- 行动计划
