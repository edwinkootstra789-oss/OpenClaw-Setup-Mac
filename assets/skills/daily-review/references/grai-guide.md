# GRAI复盘法详细指南

## Goal（目标回顾）

### 关键问题
1. 最初设定的目标是什么？
2. 目标是否符合SMART原则（具体、可衡量、可达成、相关、有时限）？
3. 是否有隐性目标或未明确表达的预期？
4. 目标在执行过程中是否发生变化？

### 常见误区
- 目标模糊，无法衡量
- 多个目标混杂，优先级不清
- 目标与实际行动脱节

## Result（结果评估）

### 评估维度
1. **完成度**：目标完成了百分之多少？
2. **质量**：完成的质量如何？
3. **效率**：投入产出比是否合理？
4. **影响**：产生了哪些预期外的影响？

### 记录格式
- 亮点（What went well）：列出3-5个做得好的方面
- 不足（What could be better）：列出3-5个需要改进的方面
- 数据支撑：尽量用数据说话

## Analysis（原因分析）

### 分析框架

#### 5 Whys（五个为什么）
针对每个关键结果，连续追问"为什么"，直到找到根本原因。

#### 鱼骨图思维
- 人：人员能力、态度、配合
- 机：工具、设备、技术
- 料：资源、信息、材料
- 法：方法、流程、策略
- 环：环境、时机、外部条件

#### 主观 vs 客观
- 主观因素：自己可以控制的
- 客观因素：外部环境决定的

### 分析原则
1. 对事不对人
2. 区分现象与本质
3. 找出可控因素
4. 避免归因偏差（如过度归因于运气）

## Insight（规律总结）

### 提炼方法
1. **模式识别**：这次的经验与以往有什么共同规律？
2. **原则提取**：可以总结出什么通用原则？
3. **方法论沉淀**：形成可复用的步骤或清单

### 输出形式
- 核心收获（3条以内）
- 改进计划（具体、可执行）
- 待验证假设（需要后续验证的想法）

## 复盘质量检查清单

- [ ] 目标是否清晰回顾？
- [ ] 结果是否有数据支撑？
- [ ] 原因分析是否深入本质？
- [ ] 是否区分了主观和客观因素？
- [ ] 规律总结是否可复用？
- [ ] 改进计划是否具体可执行？

## 复盘频率建议

- **每日复盘**：5-10分钟，记录当天关键事件
- **每周复盘**：30分钟，回顾本周重要事项
- **项目复盘**：项目结束后，深度分析
- **季度/年度复盘**：系统性回顾，调整方向
