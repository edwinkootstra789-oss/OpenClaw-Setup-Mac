# Vecspa 金融视频搜索技能 — 浏览器自动化版 v6.0.0

> **去 TikHub API 依赖**，改用 OpenClaw `browser` 工具直接操作抖音/小红书搜索页，精准检索并爬取视频数据。

## Overview

通过浏览器自动化在 **抖音** 和 **小红书** 搜索指定关键词的金融类视频，按时间筛选（24小时/一周/自定义），按点赞量排序，输出每个平台 TOP 10 的 Markdown 报告。

**核心变更（v6.0.0）：**
- ❌ 移除 TikHub API 依赖（无需 token、无需 requests）
- ✅ 使用 OpenClaw 内置 `browser` 工具直接操作网页
- ✅ URL 参数精准搜索 + 页面 UI 筛选
- ✅ 支持平台：抖音、小红书
- ✅ 输出内容不变：TOP 10 报告（标题/点赞/评论/作者/链接）

## When to Use

- 监控金融类短视频内容趋势
- 追踪金融话题热点和爆款视频
- 分析竞品金融内容策略
- 寻找金融类创作灵感
- 研究金融自媒体账号表现

**无任何外部依赖**（仅需 OpenClaw 内置 browser 工具 + 已登录的抖音/小红书网页端）。

## Before You Start

抖音和小红书的网页版搜索需要**登录状态**。在执行任务前：

1. 确保 Chrome 浏览器已登录抖音创作者平台或抖音网页版（`douyin.com`）
2. 确保 Chrome 浏览器已登录小红书创作者平台（`creator.xiaohongshu.com` 或 `xiaohongshu.com`）
3. 如果未登录，先手动登录后再开始搜索

## 搜索策略

### 抖音搜索

**搜索页 URL 结构：**
```
https://www.douyin.com/search/{keyword}?type=video
```

**时间筛选：** 抖音搜索 URL 不支持 `sort=likes&time=week` 参数（会被重定向丢弃）。需要通过页面 UI 筛选面板操作：

1. 打开 `https://www.douyin.com/search/{keyword}?type=video`
2. 找到并点击「筛选」按钮打开筛选面板
3. 点击「最多点赞」排序
4. 点击「一天内」/「一周内」时间范围
5. 关闭面板，等待结果刷新

**数据提取：** 视频卡片信息可通过 snapshot 获取，每条结果格式类似：

```
text: "57  #公积金#公积金买房 @宋行长聊金融  22小时前"
```

解析规则：
- 点赞数：行首数字
- 标题：数字后的文字（到 `@` 前）
- 标签：`#xxx` 格式提取
- 作者：`@` 后的用户名
- 时间：末尾时间文字

**点击视频获取更多数据：** 如果需要精确的点赞数/评论数，可以点击视频标题进入详情页后 snapshot 提取。

**⚠️ 重要：** 抖音的搜索结果页面是 SPA 动态加载，部分数据可能需要滚动才能完整加载。建议在搜索结果页上执行一次模拟滚动后再 snapshot。

### 小红书搜索

**搜索页 URL 结构（推荐——带筛选参数）：**
```
https://www.xiaohongshu.com/search_result?keyword={keyword}&source=web_search_result_notes&type=video&sort=general
```

**时间筛选——客户端过滤方案（推荐）：**

小红书的 SPA 搜索页不通过 URL 参数控制排序/时间。可用 UI 筛选面板（点击「筛选」按钮打开），面板内选项为 `div.tags > span` 结构。

鉴于 UI 筛选交互存在不确定性，实践中推荐**客户端过滤方案**（已验证可靠）：
1. 提取所有 `note-item` 卡片的标题、作者、时间、点赞数
2. 解析时间文本（`X分钟前`、`X小时前`、`X天前`、`MM-DD`、`YYYY-MM-DD`）
3. 客户端过滤：仅保留 24 小时内发布的内容
4. 按点赞数排序取 TOP 10

**UI 面板操作步骤（作为备选探索）：**
1. 点击页面中 `div.filter` 打开筛选面板
2. 面板内选项封装在 `div.tags` 下，包含排序/发布时间/笔记类型等
3. 选择后需点击 `.filter` 关闭面板
4. SPA 通过内部状态变更触发 API 调用，面板关闭后结果应自动刷新

小红书是 SPA 应用，部分搜索结果在 SSR 初始状态中：
```javascript
// 从 SSR 状态提取
JSON.stringify(window.__INITIAL_STATE__.search)
```

**数据提取：** 推荐使用 snapshot 方式提取搜索结果卡片。小红书搜索结果页会渲染视频卡片，包含标题、点赞数、作者等关键信息。

## 工作流程

### Step 1: 用户提供/确认搜索参数

| 参数 | 说明 | 示例 |
|------|------|------|
| **关键词** | 搜索核心词 | `公积金`, `贷款`, `理财` |
| **平台** | 抖音 / 小红书 / 都搜 | 默认两个平台都搜 |
| **时间范围** | 24小时 / 一周 / 自定义 | 默认 24h |
| **数量** | 每个平台输出多少条 | 默认 TOP 10 |

### Step 2: 浏览器搜索（抖音）

1. 检查浏览器状态：`browser({ action: "status" })`
2. 打开搜索页：`browser({ action: "open", url: "https://www.douyin.com/search/{keyword}?type=video", label: "douyin_search" })`
3. 等待 3-5 秒让页面加载
4. 检查是否有登录弹窗（扫码登录/二维码）→ 如有则跳过该平台
5. 应用时间筛选（见上方「搜索策略」）
6. 执行 snapshot 提取视频列表
7. 解析每个视频卡片：点赞数、标题、作者、时间、链接
8. 按点赞数排序取 TOP N
9. 关闭标签页

### Step 3: 浏览器搜索（小红书）

1. 打开搜索页：`browser({ action: "open", url: "https://www.xiaohongshu.com/search_result?keyword={keyword}&source=web_search_result_notes&type=video", label: "xhs_search" })`
2. 等待 3-5 秒让 SPA 渲染
3. 检查登录状态
4. 执行 snapshot 提取视频列表
5. 解析每个视频卡片：标题、点赞数、作者、链接
6. 按点赞数排序取 TOP N
7. 关闭标签页

## 数据解析参考

### 抖音 snapshot 解析

抖音搜索页的 snapshot 输出类似（compact 模式）：

```
text: "57  #公积金#公积金买房 @宋行长聊金融  22小时前"
text: "1.2w  #贷款买房 @房产咨询  05-25"
text: "325  #公积金提取 @社保达人  3小时前"
```

**解析规则：**
```
格式: {点赞数}  {#标签} @{作者}  {时间}
```

点赞数处理：
- 普通数字：直接解析为整数
- `1.2w` / `1.2万`：`1.2 * 10000 = 12000`
- 无数字（纯文字）：设为 0

时间处理：
- `X小时前` / `X分钟前` → 推算具体时间
- `MM-DD` → 当年的该日期
- `昨天` → 前一天

### 小红书 snapshot 解析

小红书搜索页的 snapshot 输出，每条视频卡片包含：

```
text: "公积金贷款额度计算  1.2万  理财小能手" （示例，实际格式以 snapshot 为准）
```

SSR 备选方案（当 snapshot 无法完整获取时）：
```javascript
// 在浏览器 evaluate 中执行
const state = window.__INITIAL_STATE__;
if (state && state.search) {
  return JSON.stringify(state.search);
}
```

## 异常处理

| 场景 | 处理方式 |
|------|---------|
| 抖音登录弹窗 | snapshot 检测「扫码登录」字样 → 跳过该平台，报告中标注 |
| 小红书未登录 | snapshot 检测登录提示 → 跳过该平台 |
| 搜索结果为空 | 报告中标注「未找到符合条件的结果」 |
| 浏览器未启动 | 先 `browser({ action: "start" })` |
| 抖音URL参数被丢弃 | 使用 UI 筛选面板替代 URL 参数 |
| snapshot 数据不完整 | 尝试滚动页面后重新 snapshot，或进入视频详情页获取 |
